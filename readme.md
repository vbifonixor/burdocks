# Burdocks

**«Лопушиный сад»** is a private PWA garden/tamagotchi-style game for my wife: a small virtual garden shaped by short care sessions, personal surprises, and our shared history.

Open the app to give sunlight, water when needed, and watch a plant grow. Sessions should take around 30–90 seconds, with no guilt or punishment for missed days. Plants cannot permanently die.

The initial scope includes:

- One plant with visible growth stages, watering, and occasional nutrients.
- Cosmetic pots and small personal tasks with rewards.
- A simple admin interface for creating tasks, sending surprises, and checking progress.
- Persistent garden progress.

The direction is warm, simple vector art and a small, self-hosted architecture. Implementation details are still being worked out.

**Burdocks** is the technical project name; **«Лопушиный сад»** is the player-facing game name.
